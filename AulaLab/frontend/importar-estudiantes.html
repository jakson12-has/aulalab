Inscribir una lista desde Excel

Seleccioná la institución y cargá un archivo .xlsx. El servidor validará los datos antes de guardar los registros.

Columnas requeridas y opcionales

Requeridas: first_name, last_name, nie, birth_date, grade_level.

Opcionales: middle_name, sex, section, guardian_name, guardian_phone.

Usá los nombres de columna exactamente como aparecen arriba. Conservá el NIE como texto para evitar perder ceros iniciales. Para las fechas, utilizá AAAA-MM-DD.

Ningún archivo seleccionado.

Importante sobre el registro

Las inscripciones se envían al servidor para validar los permisos, la institución y los datos. Los estudiantes deben esperar la aprobación correspondiente antes de activar sus cuentas. El NIE no se utilizará como contraseña.
